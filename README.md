# Meal Manager App

A Flutter-based mobile application designed to simplify meal and expense management for people living together in a shared household.

## Features

- **Member Management:** Manage household members.
- **Daily Meal Tracking:** Record and monitor daily meals for each member.
- **Grocery Expense Management:** Track shared grocery and household expenses.
- **Deposit Management:** Record member deposits and payments.
- **Monthly Reports:** Calculate meal costs, individual balances, and monthly settlements.
- **Local Database:** Store application data locally using Hive.

## Technologies Used

- Flutter
- Dart
- Hive
- Android Studio

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio
- Android emulator or an Android device

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/mdmarufmia026-afk/Meal-Manager-App-mobile-application-development-project-.git
   ```

2. Open the project directory:

   ```bash
   cd Meal-Manager-App-mobile-application-development-project-
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```

## Project Purpose

The purpose of this project is to make shared household meal management easier by organizing meal records, expenses, deposits, and monthly balance calculations in one application.
